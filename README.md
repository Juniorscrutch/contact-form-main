# Contact Form

## Overview

This project is a simple contact form built as part of a Frontend Mentor challenge. It allows users to enter their information and submit a message.

## Features

- Input fields (name, email, message)
- Basic form validation
- Responsive layout
- Clean UI

## Built with

- HTML5
- CSS (Flexbox)
- JavaScript (DOM manipulation)

## What I learned

- Handling form inputs in JavaScript
- Basic validation
- Working with events (submit)
- Structuring a simple UI
